# Proyecto Intermodular: guía para el estudiante

Guía interactiva para el alumnado de FP: del tema a la defensa del Proyecto Intermodular, con normas APA 7.

> **EN** · Interactive guide for vocational students on the final intermodular project, from topic choice to defence, with APA 7 style.

🔗 **Demo:** [proyectointermodularestudiantes.sanidadedtech.es](https://proyectointermodularestudiantes.sanidadedtech.es/)

## Para quién es

Alumnado de ciclos formativos de grado superior.

## Qué incluye

- Qué es el Proyecto Intermodular
- Fases, entregas y elección del tema
- Apartados de la memoria
- Citas y referencias en APA 7

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
